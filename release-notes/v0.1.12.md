# Octopus v0.1.12

本版本新增 Gemini 原生入站接口与 Gemini CLI 自动配置，并改善了 DSH 配置弹窗和侧边栏导航。

## Gemini 原生接口

- 新增 Gemini 原生入站协议：
  - `POST /v1beta/models/{model}:generateContent`
  - `POST /v1beta/models/{model}:streamGenerateContent?alt=sse`
  - `GET /v1beta/models`
- 支持 Gemini CLI、Antigravity CLI 等使用 Gemini 原生协议的客户端接入 Octopus。
- 修正转发时错误覆盖客户端 `X-Goog-Api-Key` 的问题，避免出现 `401 Invalid token`。

## Gemini CLI 自动配置

- 拓扑页新增 Gemini CLI 快速配置：选择 Octopus 密钥和模型分组后，自动生成：
  - `~/.gemini/.env`
  - `~/.gemini/settings.json`
- `.env` 只更新网关地址、API Key 和可选模型，保留用户注释、空行、变量顺序及其他环境变量。
- `settings.json` 只更新认证方式和可选模型名，保留其余设置。
- 保存前仍会经过冲突检测、备份和校验，确认后才写入磁盘。

## 界面改进

- DSH 配置弹窗调整为 4:3 比例并适当放大，高级设置直接展示，不再需要向下滚动展开。
- 侧边栏导航顺序调整为「首页 → 站点 → 拓扑 → 插件 → …」。
