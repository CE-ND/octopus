# Octopus v0.1.7

这一版增加实时调用拓扑、AI 客户端配置和应用内 GitHub 版本管理，并修复渠道协议显示、并发统计和 macOS 编辑快捷键。

## 新功能

### 实时调用拓扑

- 新增「拓扑」页面，查看 AI 客户端、Octopus 网关与模型分组之间的调用关系。
- 显示在途请求、调用次数、最近活动和最近请求结果；活跃链路带动态效果。
- 识别本机常用 AI 工具，在同一页面展示活跃与空闲节点。

### AI 客户端配置

- 支持编辑 Codex 和 Claude Code 配置，选择 Octopus 密钥及模型分组，并生成可调整的配置草稿。
- 支持 DeepSeek Harness 桌面 profile 的配置编辑和自动接入。
- 保存时校验配置格式、检测外部修改冲突，并以原子写入方式保存。

### GitHub 版本管理

- 「设置 → 版本信息」新增检查更新、发布历史、更新说明和安装包下载。
- 展示当前版本、构建时间与提交记录，支持跳转到对应 GitHub 提交。
- 正式更新使用 GitHub 最新正式版；发布历史同时保留预发布版本。
- 支持代理访问 GitHub、可配置的发布仓库及可选 GitHub 令牌。
- 桌面端发布页和下载链接通过系统浏览器打开。

## 修复与改进

- 修复普通渠道与站点渠道的实际出站协议显示，分组编辑器随渠道刷新更新显示信息，同时保留成员顺序、权重和关联。
- 修复并发请求下渠道、模型和 API Key 统计可能丢失增量的问题。
- 恢复 macOS 的复制、粘贴、剪切、撤销和全选快捷键。
- 改进页面高度、滚动与配置弹窗布局。
- 安装包只携带当前后端程序，减少无关打包文件。
- 发布流程在 Windows 和两种 Mac 安装包全部构建成功后统一创建 Release，使用对应版本的更新说明。

## 安装包

- **Windows x64**：Octopus 自定义安装器（`.exe`）。
- **Mac Apple Silicon**：ARM64 DMG。
- **Mac Intel**：x64 DMG。

Mac 包采用 ad-hoc 签名，首次打开方式见 [桌面端说明](https://github.com/CE-ND/octopus/blob/v0.1.7/DESKTOP.md)。
