# Octopus v0.1.11

本版本改进拓扑页实时状态、插件更新体验和 DSH 配置，并让开发桌面实例与正式实例完全隔离。

## 拓扑页

- 拓扑状态改为 SSE 实时推送，请求开始和结束时立即刷新节点与链路状态。
- 对话结束后动画随在途请求结束而停止，不再依赖 60 秒活跃窗口，也不会长时间残留。
- 断线自动重连，并在连接恢复后继续接收最新拓扑状态。
- 修复动画响应慢于实际请求的问题。

## 插件

- 插件管理页增加版本检测：插件更新后自动刷新管理页面，不再复用旧 iframe HTML。
- 插件页面接口返回 `Cache-Control: no-store`，避免浏览器继续缓存旧页面。
- 插件商城默认发布者调整为 `cend`。

## DSH 配置

- 新增 DSH 推理等级选择：Default、Off、Low、High、Max。
- 保存前校验所选模型声明的 `reasoningEfforts`，避免写入不支持的等级。
- 重新生成配置时保留已有的推理能力声明，仅补齐缺失的默认档位。

## 桌面端

- 源码开发桌面使用 `%USERPROFILE%\.octopus-dev`、18778 端口和独立 Electron userData，可与正式实例同时运行。
- `pnpm dev` 一键启动开发桌面，支持 `--no-build` 和 `--port=18779`。
- 开发配置由后端首次启动时使用与正式版相同的默认模板生成，不读取正式实例配置。
