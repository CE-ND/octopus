# Octopus v0.1.13

本版本修复 Gemini 类型站点渠道的 Base URL 被错误套用 OpenAI `/v1` 路径的问题。

## 修复内容

- 站点同步生成 Gemini 渠道时，不再自动追加 OpenAI 风格的 `/v1`。
- 修复 Gemini 请求被拼成 `POST /v1/models/...:streamGenerateContent` 后返回 `404 Invalid URL` 的问题。
- 保留显式配置的 `/v1beta`、`/v1beta2`、`/v1alpha` 版本路径。
- 站点协议路径覆盖中的 Gemini Base URL 也遵循同样的规范化逻辑。
- 增加 Gemini 渠道投影回归测试，覆盖裸域名、`/v1`、`/v1beta` 和路由覆盖场景。

## 使用说明

- 从 v0.1.12 升级后，请重新同步相关站点或渠道，让 Gemini 渠道的 Base URL 更新为不带 `/v1` 的地址。
- 如果升级后仍看到 `upstream stream ended without forwarding any payload`，表示上游返回了空流，通常是对应模型通道过载或不可用，不是 URL 拼接问题。
