# Octopus v0.1.10

本版本带来新版 Windows 原生安装指引、Windows 软件内更新，并补齐 DSH 自动配置中的图片输入声明。

## 下载安装

- **[Windows x64 · 新版原生安装指引](https://github.com/CE-ND/octopus/releases/download/v0.1.10/Octopus.Custom.Setup.0.1.10.exe)**：首次安装或从旧版本升级，请下载此文件。
- **[Mac · Apple Silicon](https://github.com/CE-ND/octopus/releases/download/v0.1.10/Octopus-0.1.10-mac-arm64.dmg)**。
- **[Mac · Intel](https://github.com/CE-ND/octopus/releases/download/v0.1.10/Octopus-0.1.10-mac-x64.dmg)**。

Windows 主安装包名称为 `Octopus.Custom.Setup.0.1.10.exe`，使用新版圆角原生安装界面。附件中的 `Octopus-0.1.10-windows-x64-setup.exe`、`.blockmap` 和 `latest.yml` 供软件内更新使用。

## Windows 安装与更新

- 使用原生 C++ / Win32 安装窗口，采用浅色渐变背景和圆角控件。
- 安装窗口先显示，点击安装后才展开安装内容，减少双击后的等待。
- 修复部分机器在卸载旧版后安装时出现的 `0xC0000005` 错误。
- 修复包含中文、空格的安装路径解析，并补充安装日志。
- 支持在软件内检查和下载更新，显示进度、取消下载和失败重试。
- 下载校验通过后，点击“重启并更新”，软件会先关闭后台服务，再在原安装目录更新并启动新版。
- 账号、配置和插件数据保留在用户数据目录，普通退出不会自动安装更新。

**升级说明：** v0.1.9 及更早版本尚未内置更新器，需要先手动安装一次 v0.1.10。后续发布的 Windows 版本可通过软件内更新安装。Mac 目前继续使用 DMG 手动更新，首次打开方式见[桌面端说明](https://github.com/CE-ND/octopus/blob/v0.1.10/DESKTOP.md)。

## DSH 图片输入

- 自动配置新增模型时写入 `input: [text, image]`，让 DSH 识别图片输入能力。
- 重新生成旧模型配置时，补齐缺失的输入类型，保留已有的手动能力声明、上下文长度和推理等级。
- 更新章鱼后需重新生成并保存 DSH 配置；实际识图能力取决于上游模型。

## 版本信息

- 发布时校验更新描述文件中的版本、安装包大小和 SHA-512。
- 手动下载列表优先展示新版 Windows 原生安装指引。
- 版本历史查询仍使用 GitHub API，可能受到 GitHub 请求限额影响；Windows 内置更新器使用公开发布信息和更新清单。
