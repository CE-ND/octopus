# Octopus v0.1.14

本版本完善 DSH 自动配置的多协议支持，并修复插件渠道卸载/重装时残留孤儿渠道的问题。

## DSH 自动配置

- 新增 **Google Generative AI (Gemini)** 协议选项，DSH 可使用 Octopus 的 Gemini 原生入站接口。
- DSH 自动配置改为 **按协议拆分 provider**：
  - `octopus-chat`（OpenAI Chat Completions）
  - `octopus-responses`（OpenAI Responses）
  - `octopus-anthropic`（Anthropic Messages）
  - `octopus-gemini`（Google Generative AI，`/v1beta`）
- 每个模型分组可以单独选择协议，不同协议互不影响，不再因为切换一个模型的协议而导致其他模型请求失败。
- 快速配置界面改为「模型路由」列表：可为每个模型分组选择协议，支持添加/删除，并单独指定默认模型。
- 为每条模型路由补齐推理等级声明，DSH 模型选择器可以正常显示该模型的推理等级；已有自定义映射和显式 `false` 会保留。
- 旧版单一 `providers.octopus` 配置会自动迁移到对应协议 provider，`magpie`、`tokenhub` 等其他 provider 原样保留。

## 插件

- 修复插件卸载后残留孤儿渠道的问题：卸载插件时会清理没有绑定关系的同名 `Plugin: ...` 渠道。
- 修复插件重装时因同名渠道触发 `UNIQUE constraint failed: channels.name` 而无法创建渠道的问题：
  - 现在会接管同名的旧插件渠道，更新其 Base URL、模型、类型和密钥，并补建绑定关系。
  - 渠道 ID 保持不变，原有分组引用不会丢失。
